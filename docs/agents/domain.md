# Domain Docs

## Before exploring

Read the root `CONTEXT.md`. If `CONTEXT-MAP.md` exists, follow it to the relevant context. Read any relevant decisions in `docs/adr/` when that directory exists.

## Repository layout

This is a single-context repository. `CONTEXT.md` is the project glossary; `docs/adr/` holds hard-to-reverse decisions when they are created.

## Vocabulary

Use terms as defined in `CONTEXT.md` in specs, issues, test names, and implementation notes. Do not introduce avoided synonyms. Surface any conflict with an existing ADR instead of silently overriding it.
